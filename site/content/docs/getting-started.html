title: Getting started desc: Requirements, building and installing rsimgv, and what happens the first time you run it. ---

rsimgv is built from source with Meson, which runs Cargo for you. An Arch Linux package recipe is included for those who prefer a package.

Requirements

Build time

  • Rust (stable) with cargo
  • A C compiler and pkg-config
  • Meson 1.2 or newer, and Ninja
  • GTK 4.22 or newer with development headers (gtk4)
  • libadwaita 1.9 or newer (libadwaita-1)
  • libmpv 2.0 or newer (mpv), which videos are played with
  • OpenCV 4.5 or newer (opencv), with Clang (clang) so the Rust bindings can generate against it
  • sassc, to compile the stylesheets
  • glib-compile-resources and glib-compile-schemas, which are part of GLib

Optional

  • Python plugin support needs python3-embed 3.10 or newer and pygobject-3.0 3.50 or newer. It is built by default when both are found; configure with -Dpython=auto, -Dpython=enabled or -Dpython=disabled.
  • The SVP plugins are built from the open-svpflow source in third_party/ and embedded, so no separate SVP installation is needed. See SVP frame interpolation.

Run time

The built program embeds its interface, stylesheets, icons and the SVP plugins in a GResource bundle, so it needs nothing beyond the shared libraries it links. Two optional tools improve video metadata and previews: ffprobe reads a video's duration, codecs and frame rate, and ffmpeg makes the frames a video shows when it is previewed.

Build and install with Meson

git clone https://git.topher.au/topher/rsimgv.git
cd rsimgv
meson setup builddir --prefix=/usr/local
meson compile -C builddir
meson install -C builddir

Installing copies the GSettings schema, the application icons, the desktop file and the bundled plugins into the system data directories. The desktop file lets rsimgv open pictures and videos from other applications.

Helper scripts

The scripts/ folder wraps the same steps:

scripts/build.sh
Configures builddir/ and compiles. --release optimises, --prefix DIR sets the install prefix and --clean starts from scratch.
scripts/install.sh
Builds an optimised rsimgv and installs it, under /usr/local unless you pass --prefix. --destdir DIR stages the files a package would contain without touching the system.
scripts/dist.sh
Packs the source tree into rsimgv-VERSION.tar.gz for packaging.

Arch Linux

A PKGBUILD lives in packaging/arch/. It depends on gtk4, libadwaita, mpv, opencv and glib2, and builds from the archive that dist.sh writes beside it:

scripts/dist.sh
cd packaging/arch
makepkg -si

Running from the source tree

For development, dev.sh sets up the build directory if needed, rebuilds, and runs the app from it, with the schema and resource bundle pointed at the build directory:

./dev.sh              # rebuild and run rsimgv
./dev.sh ~/Pictures   # extra arguments go to rsimgv
./dev.sh test         # rebuild and run the test suite
./dev.sh cargo check  # run a Cargo command in the build environment

First launch

With no arguments, rsimgv opens a window on the folder that was open when you last closed it, falling back to your home folder. Change that with the Start location setting: the last open folder, the root folder, your home folder, or a specific folder.

  1. Pick a folder
    Click a folder in the tree, or press Ctrl+L and type a path.
  2. Open a picture
    Double-click it, or move the cursor with the arrow keys or W A S D and press Enter or E.
  3. Step through the folder
    Use , and . for the previous and next item. Press Q or Esc to go back to the grid, or B to toggle the viewer.
  4. See what else is bound
    Press F1 for the keys in force where you are, or Ctrl+, for the preferences.

Where your data lives

Settings are kept as YAML in ~/.config/rsimgv/rsimgv.conf, beside your keybindings, bookmarks, playlist and per-file settings. The metadata index and viewing history are in ~/.local/share/rsimgv/media-index.sqlite3, and thumbnails are cached under ~/.cache/rsimgv. See Files and folders for the full list.

Trying it without touching your settings

Launching rsimgv rewrites start.last-directory and start.last-file in your real configuration file. To experiment without that, point RSIMGV_CONFIG and RSIMGV_DATA at other files and folders, or give it empty XDG_CONFIG_HOME, XDG_CACHE_HOME and XDG_DATA_HOME directories.
