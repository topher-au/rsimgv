title: Remote control (IPC) desc: Drive a running rsimgv from other programs with its JSON interface over a Unix socket, TCP or HTTP: every method, with examples. ---

A running rsimgv can be driven by other programs. Anything you can do with a key, you can do with a request: run an action, open a tab, select a file, ask what the viewer is showing, take a screenshot of it, or put a message on screen.

Turn it on

The interface is off by default. Enable one or more transports under General → Remote control in the preferences, and they start or stop straight away.

Allow other machines

The TCP and HTTP ports accept only localhost unless you turn on Allow other machines to control rsimgv, which makes them listen on every interface. Anyone who can reach them can control rsimgv, and there is no authentication, so only do this on a network you trust.

HTTP refuses a request without the JSON content type. A web page cannot send that cross-site without a preflight request, which rsimgv never answers, so other sites cannot drive it through your browser.

Protocol

A request is a JSON object with an id, a method and params. The answer carries the same id and either a result or an error with a short code to match on and a message for people.

{"id": 1, "method": "tabs.list", "params": {}}

{"id": 1, "result": {"tabs": [{"id": 1, "index": 0, "path": "/home/me/Pictures", "active": true}]}}
{"id": 1, "error": {"code": "...", "message": "..."}}

Requests are carried out on the window's own thread, so they see exactly what you see. A request that is not answered within five seconds is given up on.

Examples

# HTTP
curl -s http://localhost:9780/ipc -H 'Content-Type: application/json' \
  -d '{"id":1,"method":"navigate.to","params":{"path":"/home/me/Pictures"}}'

# Unix socket, one line in and one line out
echo '{"id":1,"method":"window.info","params":{}}' | socat - UNIX-CONNECT:$XDG_RUNTIME_DIR/rsimgv.sock

# TCP
echo '{"id":1,"method":"files.selected","params":{}}' | nc localhost 9700
import json, urllib.request

def call(method, **params):
    request = urllib.request.Request(
        "http://localhost:9780/ipc",
        data=json.dumps({"id": 1, "method": method, "params": params}).encode(),
        headers={"Content-Type": "application/json"},
    )
    reply = json.load(urllib.request.urlopen(request))
    if "error" in reply:
        raise RuntimeError(reply["error"]["message"])
    return reply["result"]

call("navigate.to", path="/home/me/Pictures")
print(call("view.info"))

The repository's scripts/get_screenshot.py is a complete small client: it asks view.info for what the viewer shows and view.screenshot for a PNG of it.

Actions

actions.list
Lists every action: name, label, description, its default scope, the contexts it can be bound in, its icon and its default key defaults.
actions.run {"name", "value"?}
Runs the action name, with value for the actions that take one, such as video.seek. win.notify takes {"message", "level"?, "seconds"?} instead and shows the message over the window.

All the names are in the action table. For instance, {"method": "actions.run", "params": {"name": "video.play-pause"}} toggles playback.

Window

window.info
Returns current_path, selected_file and show_sidebar.
window.set_show_sidebar {"show"}
Shows or hides the sidebar.

Tabs

tabs.list
Returns tabs: each with an id, its index, its path and whether it is active.
tabs.current
Returns the selected tab's id and index, both null when no tab is open.
tabs.open {"path", "activate"?}
Opens a tab on a folder. activate defaults to false, so it opens in the background. Returns its id and index.
tabs.activate {"index"} or {"id"}
Selects a tab.
tabs.close {"index"}
Closes a tab.
tabs.files {"tab"}
Lists a tab's files: name, path and is_dir.
tabs.select {"tab", "file"}
Selects a file in a tab, by name or path. Returns the selected name.

Wherever a tab is asked for, it is a tab's id, or "current" for the selected tab. An index is a tab's position counted from 0 in tab order.

Navigation

navigate.back, navigate.forward, navigate.up {"n"?}
Go back, forward or up n times (default 1). Returns how many it moved. Up stops at the root.
navigate.to {"path"}
Browse a folder.
navigate.next, navigate.previous
Go to the next or previous folder in tree order. Returns its path, or null at the end or start.
navigate.next_media, navigate.previous_media
Go to the next or previous folder that has a picture or video, or return null if there is none.

Files

files.list {"path"?}
With no path, the selected tab's items in the order the tab shows them. With a path, that folder's contents from disk, including hidden files, sorted by name. Returns files, an object keyed by name with each file's path, is_dir, size and modified.
files.select {"file"}
Selects a file in the selected tab, by name.
files.select_index {"index"}
Selects by position; a negative index counts from the end.
files.selected
Returns the selected file's name and index, or null when nothing is selected.

Bookmarks

bookmarks.add {"path", "name"?}
Bookmarks a folder. The name defaults to the folder's own.
bookmarks.remove {"path"}
Removes a bookmark.
bookmarks.list
Returns bookmarks, each with a name and a path.

The viewer

view.info
Describes the item the viewer shows: directory, filename, mime_type, width and height in pixels, and for videos position and duration in seconds, fps and speed. The playback values are null for a picture, and duration, fps and speed are null when a video does not report them yet.
view.screenshot
Returns the picture or video frame the viewer shows, at its own size, as base64-encoded PNG in data, with its format, width and height.
import base64
shot = call("view.screenshot")
open("frame.png", "wb").write(base64.b64decode(shot["data"]))

Messages

messages.show {"text", "level"?, "position"?, "persistent"?, "seconds"?, "dismissible"?}
Shows a message over the window and returns its id. level is info (the default), success, warning, error or plain. position is top-left, top-center, top-right, bottom-left, bottom-center (the default) or bottom-right. It goes away after seconds (4 by default) unless persistent is true, when it stays until dismissed. dismissible puts a close button on it, which a persistent message has unless it is false.
messages.update {"id", "text"}
Changes the text of a message that is still up.
messages.dismiss {"id"?}
Takes a message down; with no id, every message.

Ideas

  • A hotkey daemon or stream-deck button that sends actions.run for video.play-pause or view.next.
  • A sorting workflow in which a script calls files.selected, files the picture away, then calls actions.run with view.next.
  • A kiosk or slideshow controller that calls navigate.to and steps the viewer on a timer.
  • A progress display for a long job, using messages.show and messages.update.
