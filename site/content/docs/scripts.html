title: Scripts and messages desc: Run your own commands on files from rsimgv, and show notifications and persistent messages over the window. ---

Scripts turn rsimgv into a launcher for whatever you do with files: send one to an editor, copy its path, upload it, rate it. Messages are how rsimgv, and the programs that drive it, tell you what happened.

Scripts

A script is a name, a command and a flag. They live on the Scripts page of the preferences, where Add, Edit and Remove manage the list.

{{shot prefs-scripts "The Scripts page of the preferences"}}
Name
What the script is called in the list and in the keybinding editor.
Command
Run by your shell. %file% stands for the path of the item it is run on, and is safe to use with spaces and other awkward characters in the path, because it is passed to the shell as an argument rather than pasted into the command line.
Wait
Whether rsimgv waits for the command to finish. If it waits, the folder is listed again when the script ends, so a script that renames, converts or deletes files shows its result in the grid.

Examples

gimp %file%
exiftool %file% | wl-copy
convert %file% -resize 50% %file%.small.jpg
notify-send "Rated" "%file%"

Running a script from a key

In the keybinding editor, the Run Script action binds a key to one of your scripts. Each binding picks its script, so one action serves any number of keys. It runs on the item under the cursor while browsing, or on the item the viewer shows.

A script that fails reports it with a message over the window.

Scripts are saved in the scripts setting, a list of JSON objects with name, command and wait.

Messages

Messages appear over the window, in the corner or edge you choose. There are two kinds:

  • Notifications go away by themselves after a few seconds (4 by default).
  • Persistent messages stay until they are dismissed, and have a close button unless asked otherwise.

Each has a level, which sets how it looks: info, success, warning, error, or plain for bare text.

From a key

The Show Notification action binds a key to a notification. Each binding sets its message, its level and how many seconds it stays, up to 600. It is handy as feedback for another binding or a script.

From another program

Through the remote control interface, a program can show a message with messages.show (choosing its position, whether it persists, and whether it can be dismissed), change its text with messages.update, and take it down with messages.dismiss. That makes it possible to show progress of a long job from a script:

With the HTTP interface switched on:

curl -s localhost:9780/ipc -H 'Content-Type: application/json' -d \
  '{"id":1,"method":"messages.show","params":{"text":"Uploading…","persistent":true,"level":"info"}}'

Other overlays

  • F1 lists the keybindings in force where you are, and hides the list again.
  • Skipping through a video shows a progress bar and the time over it. See the seek overlay.
