title: rsimgv documentation desc: Documentation for rsimgv, an integrated file explorer and media viewer for GNOME. ---

rsimgv puts a folder tree, a browse grid and a media viewer side by side, so you can move through a library of pictures and videos without leaving the window. This documentation covers installing it, using it, customising it and driving it from other programs.

How rsimgv is laid out

The window has a sidebar holding a bookmarks list and the folder tree, and a content area to its right. The content area has a header with navigation buttons and the path bar, a tab bar when more than one tab is open, and the browse grid. Opening a picture or video replaces the grid with the viewer, which has its own header, an optional thumbnail bar, and an optional status bar. Press Q or Esc to return to the grid.

Everything you can do from the keyboard is an action, with a name such as view.next. Actions are what keybindings, scripts and the remote control interface all speak in terms of, which is why the same list appears in each of those pages.

Status

rsimgv is at version 0.1.0 and in early development. The browsing and viewing features described here work today; file operations such as copy, move and delete are still to come.
