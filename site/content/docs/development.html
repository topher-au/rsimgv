title: Development desc: Source layout, building, testing and the technology behind rsimgv. ---

rsimgv is written in Rust with GTK 4 and libadwaita. It is free software under the GPL-3.0-or-later, and its source is on git.topher.au.

Source

  • git.topher.au/topher/rsimgv, the main repository.
  • github.com/topher-au/rsimgv, a mirror of the main branch.

Technology

PartUsed for
Rust, gtk4 0.11 and libadwaita 0.9The application and its interface.
MesonThe build, which runs Cargo, compiles the stylesheets with sassc, builds the GResource bundle and installs everything.
GSettings with a custom backendSettings, stored as YAML. The backend is a GObject subclass in C (src/settings/backend.c) because the Rust bindings do not expose what is needed to subclass GSettingsBackend.
libmpvVideo playback, rendered in software into memory.
OpenCVBicubic resampling and sharpening of pictures.
serde_yaml_ng, serde_jsonThe YAML files and the JSON interface.
VapourSynth and SVP pluginsOptional frame interpolation.

Project layout

src/
  main.rs            application startup, actions, icon theme registration
  fs/                directory entries, lazy tree nodes, natural sort, thumbnails
  settings/          GSettings backend (backend.c) and YAML storage (store.rs)
  keybindings/       the action catalogue, chords and the binding table
  mpv/               a safe wrapper over libmpv
  ui/                widgets: window, folder tree, browse view, item grid, path bar,
                     navigation bar, viewer, thumbnail bar, preferences, overlays
  ipc.rs, remote.rs  the JSON interface and the methods it offers
  svp.rs, svp_manager.rs  SVP integration
  bookmarks.rs, folder_sort.rs, file_settings.rs, scripts.rs
data/
  ui/                GTK XML templates for every window and widget
  style/             SCSS, compiled to CSS at build time
  icons/             application and symbolic icons (hicolor theme layout)
  *.gschema.xml      GSettings schema
  rsimgv.gresource.xml  bundle manifest
build-aux/           build helper that runs cargo from Meson
scripts/             build, install, dist and test helpers
packaging/arch/      PKGBUILD

Building and testing

./dev.sh          # rebuild and run rsimgv
./dev.sh test     # rebuild and run the test suite
scripts/test.sh   # the same, or only tests whose names contain an argument

The tests need a display. On a machine without one, scripts/test.sh runs them under xvfb-run -a. They run on a single thread, because GTK runs on one.

Design notes

  • The browse grid is its own widget. Only the items on screen have widgets, rows are filled left to right and the block of rows is centred, so folders with many files stay responsive.
  • Thumbnails are demand-driven. A few are made at a time, and a request that nothing on screen wants any more is dropped before it runs.
  • Everything is an action. The keybinding table, scripts, notifications and the remote control interface all resolve to the same catalogue of named actions.
  • Settings apply live. The YAML file is watched, and a change made in the file, the dialog or the menu has the same effect at once.

This website

This site is a separate repository. Its pages are HTML fragments that a small Python script wraps in the site layout; the keybinding and settings references are generated from rsimgv's own source, so they cannot drift from the code.
