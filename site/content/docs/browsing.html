title: Browsing folders desc: The folder tree, the browse grid, selection, sorting, filtering, thumbnails and folder previews in rsimgv. ---

The browse view shows the current folder as a grid of folders and files. Beside it, the sidebar's folder tree lets you jump anywhere on the file system.

{{shot browse-grid "The browse grid, the folder tree and the status pill at the bottom right"}}

The folder tree

The tree is rooted at /. Folders expand on demand, so opening a deep path never walks the whole disk. Selecting a folder in the tree browses it and reveals its path; a path is framed so that the folder and as many of its children as fit are on screen.

  • Click a folder to browse it, or its arrow to expand or collapse it. Double-click toggles expansion too.
  • Middle-click a folder to open it in a background tab.
  • By default, expanding a folder leaves the others open. Turn on Collapse other folders when navigating (browse.collapse-on-navigate) to close the folders outside the current path each time you move.
  • Drag the edge between the sidebar and the content to resize it. The width is remembered.
  • F9 shows or hides the sidebar.

The browse grid

Folders come first, then files, each in natural name order, so numbered files sort the way you expect. The grid lays out only the items on screen, which keeps folders with thousands of entries responsive. A pill at the bottom right says what is selected and how large it is.

Entering a folder with nothing chosen starts the cursor on its first item.

Selecting several items

Ctrl-click toggles an item's mark, Shift-click marks the range to it, and Ctrl+A marks every item. Clicking on empty space clears the marks. Marked items are what a drag carries, and what actions act on together.

Dragging to other applications

Drag an item out of the grid and other applications receive it as a file, as the text/uri-list of its location. If the item is one of the marked ones, the whole marked set travels. A list of files dropped onto rsimgv is read back the same way.

What is listed

Media only
By default only pictures and videos appear, plus folders. Turn browse.media-only off, or press Ctrl+M, to see every file.
Hidden files
Hidden files and folders are not listed unless you turn on browse.show-hidden from the main menu or with Ctrl+H.
Directories
browse.show-directories chooses where folders go: first-last puts them before the files when the order is ascending and after when it is descending, inline sorts them among the files, and none hides them.

Sorting

The sort menu in the header sorts by Alphabetical, Modification Time, Size or Type, ascending or descending. By default a choice changes the default for every folder. Turn on Remember folder sort settings (navigation.remember-folder-sort) and the menu changes only the folder you are in, which keeps that sort the next time you open it; folders without one use the default sort and order from General → Folder Navigation.

Remembered sorts are kept in folder_sort.yaml; see Files and folders.

Item appearance

{{shot prefs-browsing-items "Browsing preferences: items"}}
Item size
The size in pixels of each item's picture or icon, from 32 to 2048. Ctrl+= and Ctrl+- make items larger and smaller.
Filename
Names can be ellipsized, wrapped over two lines, or hidden (off).
Item info
A line under the name with the details you choose, in the order you set, laid out inline separated by bullets, stacked one per line, or disabled. Fields are size, modified time, content type, resolution, duration, frame rate, codec, bit rate and audio.
Crop thumbnails
Fill each item's square with its picture, cutting off the edges, instead of fitting the whole picture in.
Tooltip
Resting the pointer on an item shows its description: name, type, path, size and modification time. A selection keeps the previews until the pointer moves, and browse.show-tooltip can be bound to a key to show the tooltip for the item under the cursor.

Thumbnails

Pictures and videos show a thumbnail. They are made in the background, a few at a time, by a pool of threads, and a request that no item on screen wants any more is dropped before it runs, so scrolling past thousands of items does not queue up work.

{{shot prefs-browsing-thumbnails "Browsing preferences: thumbnails"}}
  • A video's still thumbnail is a frame a tenth of the way in. With Video frame previews on, resting the pointer on a video plays a sequence of frames spread through it. They come from ffmpeg and are cached.
  • Thumbnails are cached on disk in ~/.cache/rsimgv, so they are not made again the next time they are shown. A thumbnail is reused while the file's modification time is unchanged, and thumbnails not made for a while are swept away at start-up.
  • Thumbnails that scroll out of view can be released from memory and loaded again when they return. Both the cache and this release are settings under Advanced.
  • How many thumbnails are made at the same time is the Thread count, at most the number of threads on the system.

Folder previews

With Show folder previews on, each folder's icon carries a cascade of the first pictures and videos inside it.

{{shot folder-previews "Folders with previews of the pictures inside them"}}
  • Folder previews sets the most pictures and videos shown, from 1 to 12.
  • Fit previews to pictures shows as many as their dimensions allow instead of a set number.
  • Cycle folder previews steps the preview through the folder's media while the pointer is over the folder, or while it is the item last selected and the pointer is over none.
