title: Settings reference desc: Every rsimgv setting with its YAML name, default and allowed values, and how the configuration file works. ---

Settings live in a YAML file and apply the moment they change, whether you edit them in the preferences dialog, from the main menu, or in the file itself while rsimgv runs.

The configuration file

Settings are stored in ~/.config/rsimgv/rsimgv.conf. Set RSIMGV_CONFIG to use another file. rsimgv reads and writes them through GSettings, using a backend that stores them in that file, so the schema (data/au.topher.rimgv.gschema.xml) defines what exists, what each setting is for and what values it accepts. A setting that is missing from the file has its default.

window:
  width: 1280
  height: 800
  maximized: false
browse:
  show-hidden: false
  media-only: true
  item-size: 160
  filename-display: ellipsized
  show-directories: first-last
  info-fields: [size, modified, resolution]
navigation:
  folder-end: next-folder
  remember-folder-sort: true
viewer:
  image-preloading: true
  thumbnail-bar:
    side: bottom
    pinned: true
image:
  fit: window
  keep-fit: true
  original-focus: center
  zoom-step: 25
  scaling-filter: cubic-sharp
video:
  backend: mpv
  seek-overlay-position: top-middle
thumbnails:
  threads: 4
  cache: true
  unload-offscreen: true
remote:
  http-enabled: true
  http-port: 9780

Each setting is written as group.name, as in the first column of the tables below, and a dot in a name is a nested mapping, so viewer.thumbnail-bar.side is written as thumbnail-bar: then side: under viewer:. The second line of each entry is the setting's key in the schema, which is what gsettings and the source use. Settings that have no group of their own are kept under settings: with their schema key, such as settings.directory-previews.

Where the dialog puts things

The preferences dialog is organised by task, not by group: General, Browsing, Viewer, Images, Videos, Controls, Scripts and Advanced. It has a search box, reached with the magnifier in its header, that finds a setting by name or description.
