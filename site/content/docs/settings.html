title: Settings reference desc: Every rsimgv setting with its YAML name, default and allowed values, and how the configuration file works. ---

Settings live in a YAML file and apply the moment they change, whether you edit them in the preferences dialog, from the main menu, or in the file itself while rsimgv runs.

The configuration file

Settings are stored in ~/.config/rsimgv/rsimgv.conf. Set RSIMGV_CONFIG to use another file. rsimgv reads and writes them through GSettings, using a backend that stores them in that file, so the schema (data/au.topher.rsimgv.gschema.xml) defines what exists, what each setting is for and what values it accepts. A setting that is missing from the file has its default.

window:
  width: 960
  height: 640
  sidebar:
    width: -1
browse:
  media-only: true
  item-size: 128
  info:
    layout: inline
    fields: [size, modified]
  sort:
    by: name
    order: ascending
viewer:
  folder-end: stop
  thumbnail-bar:
    side: bottom
    shown: true
image:
  fit: window
  keep-fit: true
  scaling-filter: linear
video:
  backend: mpv
  crop:
    enabled: false
    method: cropdetect
  svp:
    enabled: false
playlist:
  repeat: true
remote:
  http:
    enabled: false
    port: 9780

The file is nested by each setting's GSettings key path below the schema's path, /au/topher/rsimgv/. Each setting holds its plain value, and its type comes from the schema. A dot in a name below is a nested mapping, so viewer.thumbnail-bar.side is written as thumbnail-bar: then side: under viewer:.

A value that does not fit its setting's type is kept in the file as written and ignored, and the setting uses its default. A file that cannot be parsed makes the settings read-only until it is fixed and the app restarted, so it is never overwritten. If the installed schema is older than the build, rsimgv says so and asks you to reinstall rather than panicking on the first missing setting.

Where the dialog puts things

The preferences dialog is organised by task, not by group: General (General, Remembered), Browsing (Items, Folders, Playlist), Viewer (Display, Thumbnails, Overlay), Images (Fit and zoom, Display), Videos (Playback, Framing, SVP), Controls (Keyboard, Mouse), Integration (Scripts, Plugins, Remote control), Performance and About. It has a search box, reached with the magnifier in its header, that finds a setting by name or description.
