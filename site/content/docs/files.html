title: Files and folders desc: Where rsimgv keeps its configuration, bookmarks, per-file settings, thumbnail cache and sockets. ---

rsimgv keeps its data in ordinary files in standard places. Everything it writes is plain text you can read, back up and edit, apart from the thumbnail cache.

Configuration: ~/.config/rsimgv/

This is $XDG_CONFIG_HOME/rsimgv if that is set. The settings file can be moved with RSIMGV_CONFIG, and the files below sit beside it.

FileHolds
rsimgv.confYour settings, as YAML. It also records the folder and file that were open when you last closed the window.
keybindings.yamlThe keys that differ from the defaults. See the bindings file.
bookmarks.yamlYour bookmarked folders, each with a name and a path.
folder_sort.yamlThe sort chosen for each folder, while Remember folder sort settings is on.
file_settings/Settings for each media file; see below.
mpv/mpv's own config directory for rsimgv's player: mpv.conf and any scripts. See Configuring mpv.

The files are written atomically, so a crash or a power cut does not leave a half-written file.

Per-file settings

The viewer keeps what you did to a media file: a video's play position and speed, and a picture's zoom and pan. They are found by the file's contents, not its path, so they follow a file that is moved or renamed.

A file is known by its movie hash: its size plus every 64-bit little-endian word in its first and last 64 KiB, written as 16 lowercase hexadecimal digits. Its settings are one YAML file, file_settings/<first character of the hash>/<hash>.yaml, with every value at its root:

position: 93.5
speed: 1.25

To forget everything remembered about your files, delete the file_settings folder.

Thumbnail cache: ~/.cache/rsimgv/

Thumbnails are PNG files grouped by size, with a metadata folder alongside them, and video preview frames are cached beside them. Thumbnails that have not been made for a while are removed in the background when rsimgv starts; one that is needed again is simply made again. The whole folder is safe to delete. To stop using it, turn off Enable thumbnail cache in Advanced, and thumbnails then last only as long as they are in memory.

Sockets

PathWhat
$XDG_RUNTIME_DIR/rsimgv.sockThe remote control Unix socket, when enabled. Its path can be changed in the preferences.
/tmp/rsimgv-mpv-<pid in hex>mpv's JSON IPC for the running player. Appears once a video has been opened.
/tmp/com.svpteam.svpThe SVP manager socket that rsimgv serves while SVP is on.
