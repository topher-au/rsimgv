title: Command line desc: Opening files and folders from the command line, the options rsimgv takes, and how a running rsimgv takes over a second launch. --- 
rsimgv [OPTION...] [FILE_OR_FOLDER...]

Arguments

Each argument opens in a new tab of the open window, or of a new window if none is open.

  • A folder opens in its tab.
  • A file opens a tab on its folder with the file selected, and a picture or video also opens in the viewer.

A running rsimgv takes the arguments of a second launch, so rsimgv photo.jpg from a terminal or a file manager adds a tab to the window you already have instead of starting another copy.

Options

--version, -V
Print the version and exit.
--verbose, -v
Print the debug output, including what the metadata and thumbnail work is doing.
--new-window
Open the paths, or the default folder with no paths, in a new window.
--new-tab
Open the paths, or the default folder with no paths, in a new tab.
--select-item
Show each path's containing folder with the path selected, instead of opening the path. Useful for a file manager's "reveal" command.

Without a flag, the first path replaces the folder shown in the current tab and the rest open in background tabs.

As the default viewer

The installed desktop file declares image/* and video/* and runs rsimgv %F, so rsimgv appears in "Open With" lists for pictures and videos and can be chosen as the default application for them.

Environment

RSIMGV_CONFIG
Use another settings file instead of ~/.config/rsimgv/rsimgv.conf. The files kept beside it, such as keybindings.yaml, playlist.xspf and file_settings/, move with it.
RSIMGV_DATA
Use another folder for media-index.sqlite3, instead of ~/.local/share/rsimgv.
RSIMGV_PLUGINS
A colon-separated list of plugin folders to search, instead of the usual XDG data directories. Useful while developing a plugin.
XDG_CONFIG_HOME, XDG_CACHE_HOME, XDG_DATA_HOME, XDG_RUNTIME_DIR
Move the configuration, thumbnail cache, data and runtime directories, as for any XDG application.

Development builds that are run from the source tree also read GSETTINGS_SCHEMA_DIR and RSIMGV_GRESOURCE, which dev.sh sets to the build directory.
