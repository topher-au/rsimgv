title: Command line desc: Opening files and folders from the command line, and how a running rsimgv takes over a second launch. --- 
rsimgv [FILE_OR_FOLDER...]
rsimgv --version

Arguments

Each argument opens in a new tab of the open window, or of a new window if none is open.

  • A folder opens in its tab.
  • A file opens a tab on its folder with the file selected, and a picture or video also opens in the viewer.

A running rsimgv takes the arguments of a second launch, so rsimgv photo.jpg from a terminal or a file manager adds a tab to the window you already have instead of starting another copy.

As the default viewer

The installed desktop file declares image/* and video/* and runs rsimgv %F, so rsimgv appears in "Open With" lists for pictures and videos and can be chosen as the default application for them.

Options

--version
Print the version and exit.

Environment

RSIMGV_CONFIG
Use another settings file instead of ~/.config/rsimgv/rsimgv.conf.
XDG_CONFIG_HOME, XDG_CACHE_HOME, XDG_DATA_HOME
Move the configuration, thumbnail cache and data directories, as for any XDG application.

Development builds that are run from the source tree also read GSETTINGS_SCHEMA_DIR and RSIMGV_GRESOURCE, which dev.sh sets to the build directory.
