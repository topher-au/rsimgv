title: SVP frame interpolation desc: Smooth video playback in rsimgv with SmoothVideo Project: requirements, output frame rate modes and options. ---

SVP (SmoothVideo Project) makes video look fluid by synthesising frames between the real ones. rsimgv can run videos played through libmpv through SVP's VapourSynth plugins, the same way SVP's own svpctl does.

{{shot prefs-videos-svp "The SVP tab of the video preferences"}}
rsimgv does not include SVP

You need SmoothVideo Project installed separately. rsimgv only loads the plugin libraries SVP installs.

Requirements

  • SVP installed, with its VapourSynth plugin libraries (libsvpflow1_vs64.so and libsvpflow2_vs64.so, or the same names without _vs64) in one directory. The default directory is /opt/svp/plugins.
  • An mpv build with VapourSynth support, because rsimgv loads SVP through mpv's vapoursynth filter.
  • The mpv video backend. The SVP page offers to switch to it when it is not the chosen one.
  • Optionally an NVIDIA GPU, for SVP's optical flow analysis on the GPU. Without it, SVP's CPU analysis is used.

Turning it on

  1. Open the SVP tab
    Ctrl+, for the preferences, then Videos → SVP.
  2. Check the plugin directory
    Point Plugin directory at the folder holding SVP's libraries.
  3. Switch on Interpolate frames with SVP
    It applies to videos you open from then on.

Output frame rate

How the rate SVP is asked to produce is chosen is the Output frame rate:

ModeOutput rate
defaultThe source's own rate, within the limits.
fixedThe target rate, within the limits.
variableThe target rate divided by the playback speed, so playing faster does not push the output past what can be made.
display (default)Your display's refresh rate divided by the speed, so the frames shown each second match the display.

In fixed and variable, a Target frame rate of 0 means the source's rate. Whatever the mode picks is rounded to a whole number of frames a second and kept between the Minimum (60 by default) and Maximum (240 by default) frame rates. Because the target follows the playback speed in the display and variable modes, slow motion and fast forward keep the output within range.

NVIDIA optical flow

NVIDIA optical flow (on by default) runs SVP's motion analysis on the GPU through SVP's second plugin, rather than on the CPU. Turn it off if you have no NVIDIA GPU.

SVP's manager socket

SVP's libraries expect to find a local server, normally run by svpctl or SVP Manager, at /tmp/com.svpteam.svp. While SVP is on, rsimgv serves that socket itself, answering handshakes and leaving SVP's settings as they are, so no other SVP process needs to be running. Each client is served on a thread of its own, so a busy main thread does not hold up the filter.
