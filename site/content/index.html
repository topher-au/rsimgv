Browse a library of pictures and videos
without leaving the window.

rsimgv is a file explorer and media viewer for GNOME. A folder tree, a thumbnail grid, a full viewer and a playlist live in one window, steered by keys you can rebind and by a remote control interface you can script.

One window, the whole library

Pictures and videos are the point, so the interface is built around moving through them quickly.

Folder tree and browse grid

A tree rooted at / or home expands on demand. The grid shows the current folder as thumbnails, folders first, in natural name order.

Keybindings in contexts

Over 120 actions, each bindable globally or only while browsing, viewing, looking at a picture, watching a video, in the playlist or in the tree. Press F1 to see what is bound where you are.

Tabs, bookmarks and history

Open folders in tabs, bookmark the places you return to, long-press back or forward to list the history, and see what you have viewed.

Remote control

A JSON interface over a Unix socket, TCP or HTTP lets other programs run actions, read metadata and thumbnails, change settings, and post messages.

Folders that show what is inside

Turn on folder previews and each folder's icon carries a cascade of its first pictures and videos. Videos play a strip of frames, or an embedded player, while the pointer is over them.

  • Item size, names and the info line are adjustable
  • Thumbnails are made by a small pool of threads and cached on disk
  • Sort by name, time, size or type, remembered per folder if you like
{{shot folder-previews "Folder previews cascade the pictures inside each folder"}}

The viewer stays out of the way

A thumbnail bar floats over the picture from any edge, a status bar shows its position, resolution and size, and the neighbouring pictures are preloaded so stepping is instant.

  • Step past the end of a folder: stop, loop, or go on to the next folder with media
  • Fit modes, a zoom step you choose, one-to-one focus on the centre, top or pointer
  • A blurred copy of the picture can fill the space around it
  • Turn and mirror a picture without changing the file
{{shot viewer-zoom "Zoomed in with the thumbnail bar and status bar showing"}}

Smooth video, if you want it

Skip through a video and a progress bar and the time appear over it. For playback that looks as fluid as it can, rsimgv can interpolate frames with SVP's VapourSynth plugins, built and embedded so SVP itself need not be installed.

  • Speed, volume, mute, repeat and auto-advance are all actions you can bind
  • Crop black bars or a blurred backdrop, and set an output aspect ratio
  • The overlay's elements, places and styling are settings
{{shot video-viewer "Skipping through a video shows the seek display"}}

A playlist that remembers

Collect pictures and videos from anywhere into one list. The made order, the shuffled order, what has been played and where you left off are all kept, in the playlist file and in the formats you export.

  • Load and save M3U, M3U8, PLS and XSPF
  • Load a playlist from a URL, keeping the files on this computer
  • Detach the panel into its own window

Install

rsimgv is built from source. Meson drives the build, and an Arch package recipe is included.

git clone https://git.topher.au/topher/rsimgv.git
cd rsimgv
meson setup builddir --prefix=/usr/local
meson compile -C builddir
meson install -C builddir

You need Rust, Meson, GTK 4.22+, libadwaita 1.9+, libmpv and OpenCV. Python plugin support is built when its dependencies are found, and the SVP plugins are built from source. The full list and other ways to build are in Getting started →
