Browse a library of pictures and videos
without leaving the window.

rsimgv is a file explorer and media viewer for GNOME. A folder tree, a thumbnail grid and a full viewer live in one window, steered by keys you can rebind and by a remote control interface you can script.

One window, the whole library

Pictures and videos are the point, so the interface is built around moving through them quickly.

Folder tree and browse grid

A tree rooted at / expands on demand. The grid shows the current folder as thumbnails, folders first, in natural name order.

A viewer for pictures

Fit to window, width, height or fill; zoom and pan with keys, mouse or wheel; bicubic and sharpened scaling made by OpenCV.

Video with libmpv

Playback by libmpv or GStreamer, a seek overlay, speed and volume control, and positions remembered per file even if you move it.

Keybindings in contexts

73 actions, each bindable globally or only while browsing, viewing, looking at a picture or watching a video. Press F1 to see what is bound where you are.

Tabs, bookmarks and history

Open folders in tabs, bookmark the places you return to, and long-press back or forward to list the history.

Remote control

A JSON interface over a Unix socket, TCP or HTTP lets other programs run any action, read what is shown, take screenshots and post messages.

Folders that show what is inside

Turn on folder previews and each folder's icon carries a cascade of its first pictures and videos. Videos play a strip of frames while the pointer is over them.

  • Item size, names and the info line are adjustable
  • Thumbnails are made by a small pool of threads and cached on disk
  • Sort by name, time, size or type, remembered per folder if you like

The viewer stays out of the way

A thumbnail bar floats over the picture from any edge, a status bar shows its position, resolution and size, and the neighbouring pictures are preloaded so stepping is instant.

  • Step past the end of a folder: stop, loop, or go on to the next folder with media
  • Fit modes, a zoom step you choose, one-to-one focus on the centre, top or pointer
  • A blurred copy of the picture can fill the space around it

Smooth video, if you want it

Skip through a video and a progress bar and the time appear over it. For playback that looks as fluid as it can, rsimgv can interpolate frames with SVP, driven by the same VapourSynth plugins SmoothVideo Project installs.

  • Speed, volume, mute, repeat and auto-advance are all actions you can bind
  • The overlay's position, bar width and time format are settings

Install

rsimgv is built from source. Meson drives the build, and an Arch package recipe is included.

git clone https://git.topher.au/topher/rsimgv.git
cd rsimgv
meson setup builddir --prefix=/usr/local
meson compile -C builddir
meson install -C builddir

You need Rust, Meson, GTK 4.22+, libadwaita 1.9+, libmpv and OpenCV. The full list and other ways to build are in Getting started →
