Get rsimgv

rsimgv is in early development. Each version is published on GitHub with an AppImage, a Flatpak bundle and a source archive. It also builds with Meson, and an Arch Linux package recipe is included in the repository.

AppImage

A single file that bundles GTK, libadwaita, mpv and OpenCV. It needs a system whose glibc is as new as the build's.

Build from source

  1. Install the build dependencies
    Rust with cargo, a C compiler and pkg-config, Meson 1.2+ and Ninja, GTK 4.22+, libadwaita 1.9+, libmpv, OpenCV 4.5+ with Clang, and sassc.
  2. Build 
    meson setup builddir --prefix=/usr/local
meson compile -C builddir
  3. Install 
    meson install -C builddir
  4. Run it 
    rsimgv ~/Pictures
The AppImage and Flatpak have no plugins

Both are built without Python plugin support, so the bundled plugins, including the MCP server, are only available in a build from source or the Arch package. Everything else, including the remote control interface, works in all of them.

Early development

Expect rough edges. General file operations such as copy and move are not built yet, apart from deleting a playlist item from disk, and the application is still changing quickly. Python plugins need python3-embed and pygobject-3.0 at build time; without them the rest of rsimgv still works.
