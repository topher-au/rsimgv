Get rsimgv

rsimgv is in early development and is distributed as source. It builds with Meson, and an Arch Linux package recipe is included in the repository.

Source

Clone the repository from git.topher.au. A mirror of the main branch is kept on GitHub.

Quick start

  1. Install the build dependencies
    Rust with cargo, a C compiler and pkg-config, Meson 1.2+ and Ninja, GTK 4.22+, libadwaita 1.9+, libmpv, OpenCV 4.5+ with Clang, and sassc.
  2. Build 
    meson setup builddir --prefix=/usr/local
meson compile -C builddir
  3. Install 
    meson install -C builddir
  4. Run it 
    rsimgv ~/Pictures
Early development

Expect rough edges. File operations such as copy, move and delete are not built yet, and the application ID (au.topher.rimgv) and the icon name (au.topher.rsimgv) do not yet agree, so the app icon may not resolve in every launcher.
