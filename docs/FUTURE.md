# Keybindings
- Multiple contexts allowing a bind to perform different actions
  - Global context
  - Browser context
  - Image context
  - Video context

Fully custom keybinding system with multiple contexts/states allowing a keybind to activate different actions depending on whether you're browsing a folder, viewing an image, watching a video, etc.

# REST API
- Activate any actions remotely 

# Bookmarks
- Bookmark a path
- Optionally set bookmark name manually
- Collapsible list in sidebar above the folder tree.
